# AICura 포털(광고주·광고대행사) 매뉴얼

**AICura** 광고주 포털은 **광고주(병원)** 와 **광고대행사** 두 역할이 사용하는 셀프서비스 화면입니다.
계약 동의, 광고비 충전, 이벤트 신청(리드) 관리, 매출 리포트 등을 직접 수행합니다.

> 대상: 광고주(병원 담당자) · 광고대행사 담당자
> 접속: `https://<서비스도메인>/portal` (세션 로그인)
> 운영자용 관리자 패널 매뉴얼은 [admin-manual.md](admin-manual.md) 참고

## 1. 역할 안내

포털은 로그인 계정의 `is_agency_account` 값으로 역할을 구분합니다.

| 역할 | 설명 | 주요 기능 |
|------|------|-----------|
| **광고주(advertiser)** | 병원 담당자 계정 | 계약 동의, 광고 충전 신청, 신청 DB 관리, 자기 병원 리포트 |
| **광고대행사(agency)** | 여러 광고주를 관리하는 대행사 계정 | 광고주 등록·초대, 광고주별 계약 현황, 소속 광고주 합산 리포트 |

같은 포털이지만 역할에 따라 **보이는 메뉴와 화면이 다릅니다.** 이 문서에서는 역할별 차이를 함께 표기합니다.

## 2. 로그인

이메일·비밀번호로 로그인합니다. (`/portal/login`)

- **입력**: 이메일 · 비밀번호
- 로그인 후 역할(agency/advertiser)에 맞는 대시보드로 이동합니다.
- 이메일·비밀번호 오류 시 동일 메시지가 표시됩니다("이메일 또는 비밀번호가 올바르지 않습니다").
- 광고주 계정이 아직 특정 광고주(병원)에 연결되지 않았다면, 일부 기능은 **연결 초대 수락 후** 이용할 수 있습니다.

---

## 3. 대시보드

### 광고주 대시보드

- **광고주 연결 초대 배너** (미연결 시): 대행사가 보낸 초대를 **수락/거절**
- **계약 동의 알림** (미동의 시): "계약 동의가 필요합니다" → `계약 확인하기`
- **광고비 요약**: 전체 충전금 / 소진 / 현재 잔액
- **상태 카드**: 계약 상태(사용가능·계약대기), 전체 신청 건수, 미확인 신청 건수(신청DB로 이동)

### 대행사 대시보드

- **통계 카드**: 전체 광고주 수 / 계약대기 수 / 사용중 광고주 수
- **최근 등록 광고주**: 병원명·담당자·상태·계약 동의 여부·등록일 (상위 5개)

## 4. 광고주 관리 (대행사)

> **대행사 전용** 기능입니다. 대행사는 자신이 소유한 광고주만 조회·관리합니다.

### 광고주 목록

- **필터**: 병원명 / 상태(활성·정지·탈퇴)
- **컬럼**: ID, 병원명, 담당자, 연락처, 상태, 계약(계약대기·사용가능), 등록일
- **버튼**: `광고주 등록`

### 광고주 상세

- **기본 정보**: 병원명·담당자·연락처·이메일·사업자등록번호·상태·계약 동의 여부·계정 연결 상태
- **건별 수주내역**: 계약명·광고상품·상태·등록일·금액(+합계)
- **광고대행 표준계약서**: 갑(대행사)·을(광고주) 정보와 6개 조항, 동의 여부(조회 전용)
- **광고주 계정 연결 초대**: 대상 이메일 입력 후 `초대 보내기`(미연결·미초대 시에만 표시)

### 광고주 등록

| 항목 | 설명 |
|------|------|
| 병원 선택 * | 활성 병원 중 선택 → 병원명 자동 입력 |
| 병원명 * | 최대 255자 |
| 담당자명 / 연락처 / 이메일 / 사업자등록번호 | 선택 입력 |
| 광고주 로그인 계정 이메일 | 입력 시 초대 발송(병원유형·미연결 계정만 허용). 비우면 나중에 초대 가능 |

> 등록 후 광고주가 **초대를 수락 → 계약 동의**해야 광고 서비스를 이용할 수 있는 '사용가능' 상태가 됩니다.

## 5. 계약 관리

### 광고주 계약 관리

- **광고대행 표준계약서**: 계약 조항 확인 후 미동의면 `계약서에 동의`, 동의 후엔 `광고 충전 신청`
- **수주계약 목록**: 상품·계약금액·**잔액**·상태·입금 여부(입금대기·입금완료)·신청일, 상세 보기

> 계약서에 동의(`contract_agreed_at` 기록)해야 충전을 신청할 수 있습니다.

### 대행사 계약 관리

- **광고주별 계약 현황**: 병원명·상태·계약 동의 여부·수주계약 수·총 계약금액 (조회 전용)

### 수주계약 상세 (공통)

- **계약 정보**: 계약명·상품종류·계약금액·결제방식(선불/후불)·입금일
- **잔액 요약**: 현재 잔액과 입금 상태
- **거래내역**: 구분(계약충전·DB소진·환불 등)·금액(+/−)·일시

> 광고주는 **자기 병원의 수주계약만** 조회할 수 있습니다(타 병원 접근 차단).

## 6. 광고 충전 신청 (광고주)

> **광고주 전용.** 계약서에 동의한 상태여야 신청 가능합니다.

| 항목 | 규칙 |
|------|------|
| 광고 상품 * | 이벤트 / 메인배너 / 이벤트존메인배너 / CPM / 기타 |
| 충전 금액(원) * | 1원 초과 ~ **1회 한도 5,000만 원** |
| 결제 방법 * | 무통장입금(가상계좌) / 신용카드 |

신청하면 "충전 신청이 접수되었습니다. **입금 확인 후 광고 잔액에 반영**됩니다." 안내가 표시됩니다.
→ 이후 운영자(또는 대행사)가 입금을 확인하면 잔액에 반영됩니다.

## 7. 신청 DB 관리 (광고주)

> **광고주 전용.** 자기 병원으로 들어온 이벤트 신청(리드)을 관리합니다.

### 목록

- **필터**: 상태 / 키워드(이름·연락처)
- **컬럼**: ID, 신청자, 연락처, 캠페인, 상태, 광고 단가, 확인일시, 신청일시

### 상세 & 상태 변경

- **신청 정보**: 신청자·연락처·나이·성별·통화 가능 시간·디바이스·지역·유입 경로·문의 내용
- **상태 변경**: 상태 선택 후 `변경`
  - **예약(5)** 선택 → 예약 일시 입력
  - **취소(3)** 선택 → 취소 사유 입력(최대 500자)
- **메모·히스토리**: 메모 등록/삭제. 상태 변경 시 `[상태변경]` 시스템 메모가 자동 기록됩니다.

### 환불요청과 상태 잠금 (중요)

신청을 **취소(3)·중복(8)·결번(9)** 으로 바꾸면 운영자에게 **환불요청**이 접수됩니다.

| 환불요청 상태 | 화면 표시 | 상태 변경 가능 여부 |
|------|------|------|
| 대기 | "운영자 검토 중" 경고 배너 | **잠김** (변경 불가) |
| 승인 | "차감액이 복원되었습니다" 성공 배너 | 잠김 |
| 거부 | 거부 사유 표시 | **잠금 해제** (다시 변경 가능) |

> 즉, 환불요청이 대기·승인 상태인 동안에는 해당 신청의 상태를 바꿀 수 없습니다.

## 8. 리포트

### 광고주 리포트

- **연도 선택**(최근 5년)
- **AI 일일 보고서**: 매출·소진 최신 보고서(더보기로 이전 목록)
- **KPI(7종)**: 충전 / 소진 / 환불 / CPA 환불 / 잔액 / 신청 건수 / 내원완료
- **차트**: 월별 충전·소진
- **캠페인별 통계**: 캠페인명·신청 건수·내원완료·전환율·CPA 합계

### 대행사 리포트

- **전체 합계 KPI**: 광고주 수 / 충전 / 소진 / CPA 환불 / 잔액 / 신청 / 내원완료
- **차트**: 광고주별 충전·소진
- **광고주별 매출 테이블**: 병원별 충전·소진·환불·잔액·신청·내원완료 (병원명 클릭 시 상세)

> 리포트는 **자신의 범위**만 집계합니다 — 광고주는 자기 병원, 대행사는 소속 광고주 합산.

## 9. 내 정보

- **기본 정보**: 이름·전화번호 수정(이메일은 로그인 ID로 읽기전용)
- **비밀번호 변경**: 현재 비밀번호 확인 후 새 비밀번호(8자 이상)
- **내 대행사** (광고주 전용): 연결된 대행사명·담당자·연락처·이메일 표시(최신 수주계약 기준)

## 10. 광고주 연결 초대

> **광고주 전용.** 대행사가 보낸 계정 연결 초대에 응답합니다.

- **수락**: 내 계정이 해당 광고주(병원)에 연결됩니다. 재로그인 없이 즉시 반영되며, 이후 **계약 동의**를 진행합니다.
- **거절**: 초대를 거절합니다.

초대 대상은 **병원유형·미연결 계정**만 가능하며, 이미 다른 광고주에 연결된 계정에는 초대할 수 없습니다.

## 11. 핵심 흐름 요약

### 광고주 온보딩

```
대행사가 광고주 등록 (+계정 초대)
        ↓
광고주 초대 수락 → 계정 연결 확정
        ↓
광고주 표준계약서 동의
        ↓
광고 충전 신청 (상품·금액·결제방식)
        ↓
입금 확인 → 광고 잔액 반영
        ↓
신청 DB 수신 → 상태 관리
```

### 신청 건 처리 (광고주)

```
신청 목록 조회 → 상세 열람 → 상태 변경(예약/내원완료 등)
   └ 취소·중복·결번 → 운영자 환불요청 접수(상태 잠금)
```
